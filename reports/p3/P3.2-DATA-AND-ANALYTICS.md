## 1. 统一事件字段（schema v1 兼容）

新增**可选**顶层字段（旧事件仍合法，`schemaVersion` 仍为 1）：

| 字段 | 规则 | 来源 |
|---|---|---|
| `traceId` | 32 位小写 hex（W3C） | 宿主提供时 |
| `spanId` / `parentSpanId` | 16 位小写 hex | 宿主提供时 |
| `turnId` / `agentId` | ≤64 字符 | 宿主提供时 |
| `status` | `unknown/ok/error/cancelled` | 宿主或 adapter 判定 |
| `timestampMonotonic` | ≥0 数字 | 同进程耗时 |
| `adapterVersion` | ≤40 字符 | adapter 构建号 |

同步更新：

- `packages/event-schema/src/index.ts` + `schema/event.schema.json`；
- `adapters/_shared/schema-lite.mjs`：不再丢弃这些字段；
- `packages/session-manager`：`recentEvents` 保留这些字段；
- 单测：合法值接受；坏 traceId/status/单调时钟拒绝。

> 目前 **没有宿主稳定提供** traceId/spanId/turnId；字段存在但值为空，UI 不推测。DSH 插件也不提供模型请求/推理文本事件。

## 2. Analytics Engine

新包 `packages/analytics`，每个指标显式返回 `formula / inputs / evidence / limitation`：

| 指标 | 公式 | 证据类别 | 可视化 |
|---|---|---|---|
| Event rate | `λ=N(Δt)/Δt` | DERIVED | Tool Event Rate |
| Percentiles | P50/P95/P99 | DERIVED | Tool Waterfall |
| Tool waterfall | `duration=t_end-t_start`，session+run+call 关联 | DERIVED | Tool Waterfall |
| Critical path | `T=max_path Σduration_i` | DERIVED | Execution DAG（后续） |
| Jain fairness | `J=(Σx)²/(nΣx²)` | DERIVED | Agent Dispatch |
| Little's law | `L=λW`，<30 samples 返回 null | DERIVED | Research panel |
| Shannon entropy | `H=-Σp log2 p`，无真实分布→UNKNOWN | UNKNOWN/DERIVED | Model Inference Stream（后续） |
| JS divergence | `JSD(P||Q)` | DERIVED | Trace comparison（后续） |
| State transitions | `P_ij=N_ij/ΣN_ik` + 样本数 | DERIVED | Failure & Recovery |
| Context usage | `C=used/limit` | DERIVED | Context / Memory |

测试：`tests/unit/analytics.test.mjs` 6 组；覆盖窗口、缓存口径、跨会话工具配对、DAG 环检测、Jain 边界、Little 最小样本、熵/JS、状态转移、registry 元数据。
