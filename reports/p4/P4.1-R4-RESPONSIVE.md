## 2. Information architecture fix

At `max-width: 1100px` (covers 150% and 200%, leaves 125% wide):

- **Agent list is a dismissible sheet.** It is hidden by default; a new compact `AG` button (`#btn-agents`) opens it. Sessions are omitted inside the narrow sheet; agents remain scrollable. Width `min(440px, 100vw-24px)`, vertical overflow, no horizontal scrollbar.
- **Central visual is primary.** Nothing covers the canvas by default; 200% screenshot shows the full ring/field.
- **REPLAY controls stay visible** and wrap at top 74px; `PAUSE / STEP / speed / LIVE` remain reachable.
- **TRACE is a side sheet**, width `calc(50vw - 18px)`, fixed right, independently closeable and scrollable.
- **Evidence Inspector is an independent fixed sheet** on the left, width `calc(50vw - 18px)`, fixed, scrollable, and closeable. It no longer falls into document flow or paints unstyled white text.
- **No unrecoverable clipping / no horizontal page overflow.** The a11y probe asserts `document.documentElement.scrollWidth <= innerWidth + 1`.
- Topbar toggles are compact `AG`/`TR`, not colliding with icon buttons.
