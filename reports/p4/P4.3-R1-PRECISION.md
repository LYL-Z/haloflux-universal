## 1. F-11 token truth

`token-telemetry.mjs`:

- Only `output.end` `tokenCount` is per-message output.
- `run.end` turn totals and heartbeat cumulative values are **never** added to output.
- Groups are separate: `hostSamples`, `derivedSamples`, `simulatedSamples`, `unknownSamples`.
- Real output total contains **host-native only**; simulated total is a separate `SIMULATED` field.
- Invalid values (negative, fractional, non-finite, unsafe/over-range) are rejected and recorded in `invalidSamples`.
- Every sample retains `eventId`, `sessionId`, `runId`, `host`, `model`, `source`, `confidence`, timestamp, turn/step, value.
- Coverage = `outputEndWithToken / outputEndTotal`; incomplete coverage is `PARTIAL_COVERAGE`, never a complete total.
- Empty data is `UNAVAILABLE`, never 0.

Tests: `tests/unit/token-telemetry.test.mjs` 8 tests.
