# P4.2-C · Session / Run / Event Evidence Network

- Status: **PASS**
- Module: `apps/companion/renderer/evidence-network.mjs`, TRACE tab `EVIDENCE NETWORK`
- Baseline: `829f34d`

## Implementation

- Session node is built from the selected session id.
- Run nodes/ownership edges require `metadata.runId` or `runId`; no inferred ownership.
- Event nodes are sampled (max 40) and every node carries `eventId`, source, confidence, timestamp.
- Causal edges exist only when `parentSpanId` matches an observed `spanId`.
- Unmatched parents are displayed as **UNKNOWN_PARENT**, never repaired by guessing.
- Events without runId are counted as `unassignedEvents` and shown as UNKNOWN ownership.
- 20k histories are aggregated by run counts; only 40 event nodes are created.
- Causal edges and ownership edges have different classes and labels.

## Tests

`tests/unit/evidence-network.test.mjs` (3 tests):

- run aggregation/sampling;
- ownership vs causal distinction; only explicit parent span produces causal edge;
- empty/missing run degrades to UNKNOWN, no fabricated nodes.
