# P4.2-A · Central Arc Real Event Time Ring

- Status: **PASS**
- Module: `apps/companion/renderer/time-arc.mjs`, overlay in `app.js`
- Baseline: `829f34d`

## Implementation

- Event `timestamp` is the only angular position source.
- Density is aggregated into 256 bins; source buckets (host-native/derived/simulated) are preserved.
- LIVE cursor follows the latest observed event; REPLAY cursor follows `replay.events[replay.index]`.
- Pause/step/seek/2× redraw from the same deterministic index.
- Clicking a point on the arc converts angle → timestamp → nearest event and seeks the replay (replay only).
- Empty history draws nothing; missing timestamps are counted but never assigned a fake position.
- No event order is drawn as a causal edge.

## Tests

`tests/unit/time-arc.test.mjs` (3 tests):

- stable time order, counts, source buckets;

- angle/timestamp/click-nearest mapping.
