# P4.0 · 原版视觉深化（本轮）

- 基线：P3.2.1 修复后
- 结论：**PARTIAL**。真实数据已进入中央时间带、TRACE 研究面板与回放联动；原版完整弧度刻度/束流分层/专用实验画布仍待下一轮。
- 没有破坏 P3 Event Store/Replay/Supervisor。

## 1. 已实现

### 1.1 真实历史时间带

- 位置：底部 lab 抬头（`lab-ledger`）内嵌 canvas；
- 数据：`state.events` / `replay.events` 的真实 timestamp；
- 视觉：每个事件一根 1px 刻度，host-native 亮白、derived 灰蓝、simulated 暖灰；回放时额外画白色游标；
- 交互：回放模式下点击时间带按时间比例定位到最近事件并暂停；
- 意义：把真实事件密度映射到原作式“刻度/扫描线”层，不伪造事件。

### 1.2 TRACE 研究面板

- 顶栏 `TRACE` 打开；Tool Waterfall / Execution DAG / Critical Path 三个 tab；
- Waterfall 每行含真实 `eventId`、source/confidence、duration；点击打开 Evidence Inspector；
- DSH 无 `toolCallId` 时显示 `HOST_REPORTED`/`UNCORRELATED`，不伪造配对；
- 无 span 边时 DAG 降级 Timeline；无依赖数据时 Critical Path 显示 `UNKNOWN`。

### 1.3 回放联动

- REPLAY 条与 TRACE 同步；时间带游标随回放移动；
- `at` 定位、暂停/单步/倍速、LIVE 返回可用；
- 回放只读取 Event Store，不重跑模型/工具。

### 1.4 视觉风格

- 保持黑底、单色刻度、方角面板、10px 级信息密度；
- 未引入圆角玻璃卡片、彩色仪表盘或 SaaS 化布局。
