## 1. F-13 Token source/coverage — PASS

Per-source groups (`host-native`, `derived`, `simulated`, `unknown`) each have their own `outputEnd`, `withToken`, `coverage`, and `sum`.

- Real output uses only host-native `output.end` tokenCount.
- `HOST_REPORTED_COMPLETE` occurs only when host coverage is 1; `complete` is true exactly then.
- Mixed host+simulated or host+derived cannot make real coverage complete.
- Invalid token counts (negative, fractional, non-finite, unsafe/over-range) are rejected.
- `contextUsed=0` is valid and keeps its event/source; it no longer borrows heartbeat provenance.
- `contextLimit` retains source/confidence/eventId; simulated/derived limits are labeled SIMULATED/DERIVED, not HOST_REPORTED.
- Missing data remains UNAVAILABLE.

Tests: `tests/unit/token-telemetry.test.mjs` 7 targeted tests (host+sim, host+derived, zero context, simulated contextLimit, invalid values, same timestamp, model switch).
