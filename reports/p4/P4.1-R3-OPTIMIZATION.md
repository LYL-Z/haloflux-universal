## 1. F-10 replay virtual clock — PASS

Problem: `drawRateCanvas()` used `Date.now()`; replaying yesterday's execution showed “no tool events in 120s” today.

Fix:

- New `apps/companion/renderer/replay-clock.mjs`:
  - LIVE → `Date.now()`;
  - REPLAY → `replay.events[replay.index].timestamp`;
  - pause/step/seek/2x all use the cursor timestamp;
  - empty replay safely falls back to wall time.
- `drawRateCanvas(events, now)` and `drawFailureCanvas(events, now)` receive that clock.
- Replay canvases use the **visible full prefix**, not “last 200 cached events”; prepared prefix counters provide total/tool/error counts.

Regression tests: `tests/unit/replay-clock.test.mjs` (4):

- historical event at cursor vs today;
- at=0/step/seek;
- LIVE/empty fallback;
- yesterday execution yields 3 counted events under virtual clock and 0 under wall clock (the historical bug is asserted explicitly).
