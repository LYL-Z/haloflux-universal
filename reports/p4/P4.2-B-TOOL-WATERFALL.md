# P4.2-B · Bottom Tool Waterfall

- Status: **PASS**
- Module: bottom `TOOL / WATERFALL` canvas in `app.js` + `lab-waterfall-canvas`
- Baseline: `829f34d`

## Implementation

- Dedicated 54px bottom canvas (`#lab-waterfall-canvas`), separate from the rate canvas.
- Uses `toolWaterfall(events.slice(-500))`; shows the latest 12 rows, so a 20k history never renders 20k rows.
- Each row keeps `eventId`, tool name, status, duration, source, confidence.
- Rows without `toolCallId` show `UNCORRELATED` or `HOST_REPORTED`; no timestamp-proximity pairing.
- Clicking a row opens the existing Evidence Inspector for that row.
- At 200% the lab becomes a dedicated `LB` sheet containing only the waterfall; `btn-lab` triggers a redraw after layout settles so the backing store matches CSS size.
- Unavailable data shows `NO CORRELATED TOOL ROWS · EVENT STORE INTACT`; no fabricated bars.
